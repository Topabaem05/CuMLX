# 보관한 OrchardSim 측정 기록

별도 저장소 OrchardSim에서 만든 측정 기록입니다. 그 저장소의 Isaac Sim 작업은 라이선스 조건 때문에 오픈소스로 공개하기 어렵다고 판단해, 2026-11-04에 저장소를 삭제하고 CuMLX에 집중하기로 했습니다.

- 여기에는 기록만 있습니다. **기록을 만든 스크립트는 공개되어 있지 않으므로 외부에서 다시 측정할 수 없습니다.**
- 값은 측정 당시 그대로입니다. 경로의 홈 폴더만 `~`로 바꿨습니다. `isaac-sim-window-o7.json`은 이 프로젝트가 나중에 덧붙인 실험 항목 하나를 뺐습니다. 설치한 그대로의 Isaac Sim을 측정한 값은 바꾸지 않았습니다.
- 기록 안의 `docs/`, `spikes/` 경로는 삭제된 저장소의 경로입니다.
- NVIDIA는 이 기록을 지원하거나 보증하지 않습니다.
